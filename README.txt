VIGÍA C-UAS V6 — versión móvil experimental

CONTENIDO
- Cámara trasera y captura manual.
- GPS bajo demanda y enlace a OpenStreetMap.
- Aviso experimental por cambios entre fotogramas.
- Registro local e historial.
- Exportación JSON que incluye las fotografías.

INSTALACIÓN / PUBLICACIÓN
1. En el repositorio GitHub de VIGÍA, reemplaza index.html, styles.css, app.js, manifest.webmanifest y sw.js por estos archivos.
2. Sube también la carpeta icons completa.
3. Mantén GitHub Pages en main / (root).
4. Abre la URL HTTPS de GitHub Pages en Chrome.

IMPORTANTE
El aviso solo detecta cambios de imagen; no es IA ni identifica drones. Puede avisar por aves, vehículos, personas, sombras o movimiento del teléfono. Verifica manualmente.
Los datos se guardan en el almacenamiento local del navegador. Exporta el historial antes de borrar datos del sitio o desinstalar.
